# Vim quick Cheat Sheet

## Modes
- Normal mode: navigation and commands (press `Esc`)
- Insert mode: typing text (`i`)

## Basic Movement
- h → left
- j → down
- k → up
- l → right

## Enter Insert Mode
- i → insert before cursor

## Save and Quit
- :w → save
- :q → quit
- :wq → save and quit
- :q! → quit without saving

## Editing
- dd → delete line
- yy → copy line
- p → paste
- u → undo

## Navigation
- gg → top of file
- G → bottom of file
- 0 → start of line
- $ → end of line

## Search
- /word → search
- n → next result

## Tips
- Always press Esc before commands
- Vim is modal: typing vs commands
